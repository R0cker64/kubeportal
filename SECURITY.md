# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab) with steps to reproduce and the affected version. You will receive a response within 7 days.

## Supported versions

Only the latest release receives security fixes.

## Security model

The threat model and the controls in place are documented in [`docs/security-model.md`](docs/security-model.md) (Spanish).
